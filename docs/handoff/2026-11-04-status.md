## สิ่งที่ทำในรอบนี้

### เทสต์รอบสุดท้าย (QA)
ทดสอบทุกหน้า เดสก์ท็อป 1440×900 + มือถือ 375×812, EN + ไทย, ข้อมูลทดสอบขึ้นต้น `TEST QA:` และลบหมด DB กลับเท่าเดิม (ทริป 3, จุดแวะ 11, แชต 68/130 ข้อความ, รีวิว 2, โปรด 1)

### 🔴 ที่แก้
1. สลับสไตล์แผนที่แล้วเส้นทาง/จราจรหาย → `map-container.tsx` เก็บ overlay ไว้ใน registry (`addOverlay`/`removeOverlay`/`restoreOverlays`) แล้ววาดกลับตอน `style.load`; `setStyle` เรียกเฉพาะตอนสไตล์เปลี่ยนจริง (`{ diff: false }`)
2. หมุดถูกแถบหมวดบัง → `framePadding()` เว้นที่ตาม `topInset` ใช้กับทุก `fitBounds`

### 🟠 ที่แก้
- ปุ่ม 3D ไม่มีตึก + error `Style is not done loading` → รอ style/idle ก่อนเพิ่ม layer
- "No trips yet" แวบตอนโหลด → skeleton ใน `TripListColumn` (`isTripsLoading` เริ่มเป็น `true`)
- แชต "บันทึกลงทริปของฉัน" → รีเฟรชรายการ + เลือกทริปใหม่ + ปิด preview; แชตเก่าที่บันทึกแล้วขึ้น "บันทึกแล้ว" (เทียบลำดับ place id กับทริปที่บันทึก — `savedTripKeys`)
- มือถือ: popup ไม่ถูกปุ่ม "N สถานที่" บัง (`RESULTS_PILL_SPACE`), ปุ่ม popup/แชต/ประวัติ/dialog ≥ 44px
- Add to Trip หน้าสถานที่ → dialog เลือกทริป `components/trips/add-to-trip-dialog.tsx` (กันซ้ำ, ครบ 10 จุดกดไม่ได้, สร้างทริปใหม่ได้)
- ถูกส่งออกจาก admin → toast "หน้านั้นสำหรับผู้ดูแลระบบเท่านั้น" (`app/page.tsx`, ใช้ `resolveStoredLocale()`)
- ลบรีวิวถามยืนยัน
- โหมดไทย: `tagLabel()` + `tags.*` ใน locales, aria-label ของ header/ภาษา/เลขหน้า/breadcrumb, `<html lang>` ตามภาษา, ป้ายเอเจนต์, วันที่ Library

### 🟡 ที่แก้
- toast เลิกทำ 8 วินาที, แชร์จาก popup มี toast, toast เพิ่มลงทริปไม่ซ้ำ + "เพิ่มทั้งหมด" สรุปครั้งเดียว, label ของ Sonner เป็นไทย
- ประวัติแชตนับ "วันนี้/เมื่อวาน" ตามวันในปฏิทิน
- "แสดงแผนทริปอีกครั้ง" คืน preview บนแผนที่ด้วย
- ชื่อไทยใน Library / หน้ารายละเอียดทริป / การ์ดแชต (`chat/lib/place-names.ts` ใช้ catalog จาก `/map`) / หมุดทริปร่าง / toast; หน่วย กม./นาที/ม. ในการ์ดและแผงทริป

## สิ่งที่ยังเหลือ
- ชื่อทริปร่างจากแชต ("Wat Pho → …") server สร้างจากชื่ออังกฤษ (`apps/server/src/agent/domain/planning.ts:256`) และกลายเป็นชื่อทริปตอนบันทึก — ต้องส่งภาษาไป server
- ตัวเลขรวมในการ์ดแชต (จาก server) ไม่ตรงกับแผงขวา (คำนวณจาก Mapbox ฝั่ง web) เช่น 2.6 กม./3 ชม. 10 นาที vs 2.8 กม./3 ชม. 34 นาที
- ข้อมูลใน DB ยังอังกฤษ: "Rattanakosin Island" (area), ที่อยู่ทุกที่เป็น "Bangkok, Thailand", โน้ตจุดแวะที่ LLM เขียน
- หมุด 2 จุดที่ห่างกัน ~200 ม. ซ้อนทับกันได้
- server ยอมรับ CORS ได้โดเมนเดียว (`CORS_ORIGIN`) → Vercel preview deployment เรียก API ไม่ได้
- `@hono/zod-validator` ประกาศใน `package.json` ของ root แต่ server ใช้ (Dockerfile ติดตั้ง root ให้แล้ว) — ควรย้ายไป `apps/server/package.json`
- `package-lock.json` ที่ root ยังอยู่คู่ `bun.lock`
- ไฟล์ที่ไม่มีใครใช้: `components/planner/MapDetailsColumn.tsx`, `components/map/place-popup.tsx`
- `.DS_Store` ยังไม่อยู่ใน `.gitignore`
- repo อยู่ใน `~/Documents` ที่ iCloud sync → อาจเกิดไฟล์ "… 2" ซ้ำอีก (ดูด้วย `find . -name "* 2*" -not -path "*/node_modules/*"`)
- `/admin` ยังไม่ได้ทดสอบด้วยบัญชี admin
- งานใน Dashboard: เปิด leaked password protection, เปลี่ยนรหัสผ่านบัญชีทดสอบ, ลบไฟล์ทดสอบใน Storage
