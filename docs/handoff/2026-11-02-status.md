### งานเพิ่มเติม
- **แผนที่:** แก้ `/map?place=<slug>` (flyTo วนลูป + ถูกเส้นทางทริปทับ), แชตเปิดจากลิงก์แล้วค้างขนาดเล็ก, ปุ่มบนมือถือ ≥ 44px + ชื่อปุ่มไทย/อังกฤษ, ถอดปุ่ม Mapbox ที่ซ้ำ
- **LLM → Gemini:** `apps/server/src/lib/llm-config.ts` (ตั้งค่าผ่าน `LLM_*` ใน `.env`), แก้ thought signature / ข้อความท้ายเป็นของโมเดล, สลับโมเดลอัตโนมัติเมื่อเจอ 429 (`LLM_FALLBACK_MODELS`), ข้อความโควตาหมดเป็นไทย/อังกฤษ, embedding ใหม่ครบ 28 ที่ (1536 มิติ)
- **ลดการเรียก LLM:** ค้นหาด้วยโค้ดแล้วให้โมเดลเลือกครั้งเดียว (`agent/fast-research.ts`), วางแผนทริปรอบแรกด้วย `plan_itinerary` ตรง — จาก 4–5 ครั้ง เหลือ 1 ครั้งต่อคำถาม
- **ตัวจับ intent ภาษาไทย:** "จัดทริป/วางแผน/ครึ่งวัน ฯลฯ" → วางแผนทริป (`agent/intent-classification.ts`)
- **รูปสถานที่:** admin อัปโหลดรูปเข้า bucket `place-images` ได้ (`POST /api/admin/places/image`), ลบรูปเก่าเมื่อเปลี่ยน
- **สิทธิ์ admin:** ย้ายไปใช้ `app_metadata.role` อย่างเดียว (แก้ error 22023 + ช่องโหว่ที่ผู้ใช้ตั้งตัวเองเป็น admin ผ่าน `user_metadata`), แก้ลิงก์ `/login` ที่เป็น 404 → `/auth/login`
- **ระหว่าง QA:** แชตโหลดประวัติบทสนทนาได้แล้ว (`agent/conversation-history.ts`) + ส่งข้อมูลทริปปัจจุบันเข้า prompt, เมนูมือถือในหน้าแผนที่ไม่ถูกแผงทริปบังแล้ว (header `z-50`)

### 🔴 ข้อมูลแสดงผิด
1. ระยะทางทริปขึ้น "0 km" ทุกทริปในหน้า Library และหน้ารายละเอียด (หน้าแผนที่บอก 2–4 km) — น่าจะไม่ได้บันทึก/คำนวณ `total_distance_km`
2. เวลารวมในหน้า Library ไม่อัปเดตหลังแก้เวลาจุดแวะ (หน้ารายละเอียดถูกต้อง)
3. "Edit Survey" (`/onboarding`) ไม่โหลดคำตอบเดิม ทั้งที่ `user_profiles.onboarding_preferences` มีครบ
4. จุดแวะที่เพิ่มด้วย Add Stop ขึ้นหมวด "Viewpoint" และแสดง slug แทนที่อยู่ (`apps/web/src/app/map/page.tsx`, ค่า fallback "Viewpoint")
