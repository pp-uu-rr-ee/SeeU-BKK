## สิ่งที่ทำเสร็จ

### กลุ่ม 🔴 ข้อมูลแสดงผิด (จาก handoff 2 พ.ย.)
1. **ระยะทาง 0 km / เวลารวมไม่อัปเดต** — server คำนวณ `total_distance_km`, `total_minutes`, `distance_from_prev_km` เองทุกครั้งที่ POST/PUT (Mapbox walking, fallback haversine) — `apps/server/src/lib/trip-totals.ts`
2. **Edit Survey ไม่โหลดคำตอบเดิม** — `/onboarding` โหลด preferences ก่อนแสดงฟอร์ม — `apps/web/src/lib/onboarding-preferences.ts`
3. **Add Stop ขึ้น Viewpoint + slug** — หมวดตามแท็กจริง 14 หมวด (ไทย/อังกฤษ) และใช้ `address` จริง — `toStopCategory` ใน `apps/web/src/lib/trip-stop-utils.ts`
4. **ปุ่ม Share** — ลิงก์สาธารณะแบบโทเคนสุ่ม `/trips/shared/<token>` ถามยืนยันก่อนเปิด, หยุดแชร์ได้, ไม่ส่ง `user_id`/`context` ออกไป — `apps/server/src/lib/trip-share.ts`, `apps/web/src/app/trips/shared/[token]/page.tsx`

### หน้า map — ตรวจ UX และแก้
- **มือถือ:** แผงล่างเริ่มแบบย่อ แตะหัวแผงย่อ/ขยายได้, ปุ่มแชตไม่บัง Save, ไม่มี scroll แนวนอน
- **ปุ่มควบคุม:** Zoom ไม่ถูกช่องค้นหาบังอีก, แถบปุ่มกระชับขึ้น
- **popup:** เลื่อนแผนที่ให้พ้นช่องค้นหาอัตโนมัติ, อยู่เหนือแถบปุ่ม, มีปุ่ม "เพิ่มลง ‹ทริป›" (ซ่อนถ้าอยู่ในทริปแล้ว), ปุ่มสูง 44px, แสดงคำอธิบาย/รูป/ราคาจริงของจุดแวะ
- **หมุด:** จุดแวะมีเลขลำดับและไม่ถูกรวมกลุ่ม, หมุดกลุ่มเป็นวงขอบ, aria-label เป็นชื่อสถานที่
- **ค้นหา/หมวด:** แสดงผลคู่กับจุดแวะตอนเลือกทริป, แผนที่ซูมให้เห็นผลทั้งหมด, รายการพับเป็นปุ่ม "N สถานที่ · ดูรายการ" หลังเลือก, ไม่ล้างตัวกรองตอนยกเลิกทริป
- **บั๊ก clustering:** หมุดริมจอไม่ถูกวาดหลัง `fitBounds` (Mapbox จำ padding) — แก้ให้คำนวณขอบเขตจากมุมจอจริง
- **แก้ทริปที่ยังไม่บันทึก:** toast "เลิกทำ" ตอนลบจุดแวะ, ป้าย "ยังไม่ได้บันทึก", Save กดได้เฉพาะตอนมีการแก้, เตือนก่อนออกจากหน้า, โหลดรายการใหม่ไม่ทับการแก้
- **ความสูงหน้า:** พอดีจอใต้ header (เดิมเกิน 65px)

### แชตบอต
- **trip preview:** ขึ้นแผนที่ครั้งเดียวต่อคำตอบ (เดิมเด้งกลับทุก render จนปิดไม่ได้), มีปุ่ม "ปิดตัวอย่าง", "ซ่อน" บนการ์ดเอาออกจากแผนที่ด้วย + "แสดงแผนทริปอีกครั้ง", ล้างแชต/สลับแชต/แชตใหม่ เคลียร์ preview
- **เพิ่มสถานที่:** "เพิ่ม" แสดงสถานะ "เพิ่มแล้ว", ปุ่ม "เพิ่มทั้ง N แห่งลงทริป" ใช้งานได้จริง (เดิมเป็นป้ายกดไม่ได้), id จุดแวะไม่ซ้ำตอนเพิ่มพร้อมกัน
- **"ดูบนแผนที่":** ซูมไปที่สถานที่บนหน้าเดิม (เดิมเปิดหน้ารายละเอียดในแท็บใหม่), ย่อแชต/แผงล่างให้เห็น popup
- **แชตเก่า:** เก็บ UI payload ใน `agent_messages.metadata` → เปิดแชตเก่าได้การ์ดทริป/การ์ดสถานที่คืน — `apps/server/src/agent/assistant-record.ts`, `apps/web/src/components/planner/chat/lib/session-turns.ts`
- **New Chat:** ล้างหน้าต่างแชตจริง (เดิมแชตเก่าค้าง)
- **ชื่อทริปร่าง:** ตั้งจากจุดแวะ เช่น "Wat Pho → Grand Palace → Wat Phra Kaew" แทน "Suggested Trip"
- **ภาษา:** ปุ่มตอบด่วนตามภาษาของคำตอบ, ปุ่ม/ข้อความในแชตมีไทย-อังกฤษครบ, ปุ่มไอคอนมี aria-label, หน้าต่างแชตบนเดสก์ท็อปอยู่เหนือคอลัมน์แผนที่ ไม่บังแผนทริป
